# BLUN Features Overview

## Dashboard
- Agent management with live status
- Kanban board for task management
- Project manager with file tree
- Canvas for code review and merging
- Real-time activity feed
- System monitor with GPU/RAM/Disk stats

## AI Agents
- Custom personality per agent
- Persistent memory across sessions
- 20+ built-in skills (coding, marketing, legal, etc.)
- Agent-to-agent communication
- Autonomous KI-Operator

## BLUN King Chat
- Multi-language support (8 languages)
- Voice input (speech-to-text)
- Knowledge RAG (answers from your data)
- Web search integration
- Learn mode (/learn command)

## Builder Tools
- Website Wizard — describe and build websites
- Software Builder — full app scaffolding
- Landing Page Generator

## Business Features
- Stripe billing integration
- Team accounts with role-based access
- Multi-company support
- Invoice generation
- Admin panel with plan management

## Infrastructure
- Watchdog with Telegram alerts
- Auto-recovery on service failure
- Safe deploy with syntax validation
- Log rotation and memory limits
- ChromaDB auto-repair for knowledge base
