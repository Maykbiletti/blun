# Getting Started with BLUN

## Quick Start (Cloud)
1. Visit [blun.ai](https://blun.ai)
2. Create your account
3. Your KI-Operator is ready — describe what you need

## Self-Hosting
```bash
git clone https://github.com/Maykbiletti/blun.git
cd blun
npm install
cp .env.example .env  # configure your settings
npm run dev
```

### Requirements
- Node.js 20+
- PostgreSQL 16+
- Redis 7+
- (Optional) GPU for local AI models

## First Steps
1. **Create your first agent** — Give it a name, role, and personality
2. **Upload knowledge** — Feed it documents, chat history, or notes
3. **Start chatting** — Your agent learns from every interaction
4. **Add more agents** — Build your AI team for different tasks
