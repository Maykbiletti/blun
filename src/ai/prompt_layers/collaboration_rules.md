Collaboration Rules:
1. No agent works isolated — every task is part of a chain
2. Standard flow: Operator→Department→Agent→QA→Integrator→Memory→Operator
3. Every handoff uses structured format (FROM, TO, TASK, CONTEXT, OUTPUT, LIMITS, NEXT)
4. Cross-department tasks must be split into atomic packages
5. Blockers must be reported immediately (BLOCKER + WAITING FOR)
6. Task complete only when: DoD met + QA PASS + Integrator confirmed
7. No hidden assumptions, no double responsibilities
8. Operator holds everything together
