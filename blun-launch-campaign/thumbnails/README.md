# Thumbnails

In diesem Verzeichnis finden Sie die Thumbnails für die Social-Media-Posts der BLUN-Launch-Kampagne.

**Thumbnail-Konzept:**

- **Hauptmotiv:** Das BLUN-Logo in der Mitte, modern und clean.
- **Hintergrund:** Ein abstrakter, futuristischer Hintergrund in den BLUN-Farben (Dunkelblau, Türkis, Weiss).
- **Text:** "BLUN LAUNCH" in einer klaren, serifenlosen Schrift.
- **Plattform-Anpassung:** Die Thumbnails sind für jede Plattform (LinkedIn, X, Instagram, TikTok, YouTube) in den entsprechenden Formaten und Größen optimiert.
- **Dateiformate:** PNG und JPG in hoher Auflösung.
