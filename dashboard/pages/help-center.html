Help Center

Kurzanleitungen fuer die wichtigsten Operator-Workflows. Jede Sektion zeigt Zweck, Ort und Schrittfolge.

Verbindungen Dieter Funktionen Dieter Seele Tasks anlegen Verteilung
1. Wo lege ich Verbindungen (API-Keys, OAuth) an?

Alle Zugaenge liegen gebuendelt in Connections. Keys bleiben zentral und fuer Routing-Logik verfuegbar.

  1. Im Dashboard auf Connections.
  2. Provider auswaehlen (OpenAI, Anthropic, GitHub, Google).
  3. API-Key eintragen oder OAuth-Flow starten.
  4. Status auf Active pruefen, mit Test-Call validieren.
2. Was sind Dieters Funktionen?

Dieter ist Operator-Knoten: priorisiert, delegiert, ueberwacht, kann Auto-Merge triggern.

  1. In Agents Operator-Banner oeffnen, auf Steuern.
  2. Tab Tasks: Prioritaeten und Zielagenten kontrollieren.
  3. Operator-Einstellungen: Auto-Merge nur mit Checks/Gates.
  4. Watchdog beobachten, Fallback bei Fehlern.
3. Wie gebe ich Dieter eine Seele?

Seele = Prompt + Personality + SOUL/Werte-Memory. Damit laufen Entscheidungen konsistent.

  1. Auf Operator wechseln, Tab Einstellungen.
  2. System Prompt fuer Zielbild und Logik.
  3. Personality/Tonfall und SOUL/Werte ausformulieren.
  4. Speichern, mit 2-3 realen Aufgaben validieren.
4. Wie lege ich Tasks an?

Visuell im Kanban, operativ im Operator-Panel oder per API. Strukturierte Inputs verbessern Routing.

  1. Kanban: Karte, Beschreibung, Deadline, Prioritaet.
  2. Operator: Task im Task-Tab eingeben und zuweisen.
  3. API: Task mit Kontext, Skill-Hinweis, Zielkriterium posten.
  4. Status beobachten, bei Blockern frueh neu priorisieren.
5. Wie werden Arbeiten verteilt?

Skill-Match + Verfuegbarkeit + Last. Wenn kein idealer Agent frei ist, greift Fallback.

  1. Skill-Matrix laden, Skills sauber zuweisen.
  2. Auslastung in Agents/Monitor beobachten.
  3. Fallback-Regeln definieren (Team-Lead, Operator, Queue-Puffer).
  4. Ergebnisse pruefen, Routing nach Real-Performance nachschaerfen.

Tipp: Die Kurztexte werden auch als Mini-Help-Popup im Dashboard genutzt.
