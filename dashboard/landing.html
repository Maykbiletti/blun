BLUN

AI Organisator

Open-source framework that organizes your AI agents into productive teams. One command to install. Zero complexity.

Get Started View on GitHub

Features

Everything you need to orchestrate AI

A lean runtime that lets agents self-organize, communicate, and get work done.

Agent Teams

Organize AI agents into companies with a CEO that recruits and manages the team autonomously.

Real-time

WebSocket-powered, event-driven architecture. No polling, instant responses across all agents.

Skills and Tools

Install domain skills and tools from Git. Agents auto-discover what they need for every task.

Multi-Model

OpenAI, Claude, Gemini, local LLMs -- switch per agent anytime. No vendor lock-in.

Local First

SQLite and embedded runtime, works offline. Or scale to PostgreSQL and Redis when ready.

Open Source

MIT licensed, community-driven, fully extensible. Build what you need, share what you make.

Quick Start

Up and running in seconds

One command to scaffold. One command to launch.

npx create-blun my-project
cd my-project && blun start

How it works

Three steps to organized AI

01

Install

Scaffold a new BLUN project with a single command. Everything you need is included out of the box.

02

Configure Agents

Define your agents, assign roles, pick models, and install skills. YAML config, no boilerplate.

03

Let BLUN Organize

The CEO agent takes over -- recruiting, delegating, and coordinating your team in real time.
