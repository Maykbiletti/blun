FAQ

Frequently asked questions

An AI agent is a program powered by a language model (like ChatGPT or Claude) that can perform tasks autonomously. Instead of just answering questions, agents can write code, do research, send messages, and make decisions. BLUN organizes multiple agents into a coordinated team.

You need basic command-line skills to install and run BLUN. But once it is running, you interact with your agents through the dashboard or Telegram -- no coding required for day-to-day use.

OpenAI (GPT-4, GPT-4o), Anthropic (Claude), Google (Gemini), and any local model via Ollama. You can assign different models to different agents and switch anytime.

Yes. BLUN uses SQLite by default and can run entirely offline if you pair it with a local model through Ollama. No cloud dependency whatsoever.
