Modal Component Demo

Basic Usage

// Import Modal Functions
import { modalOpen, modalClose } from './components/modal.js';

// Basic Usage
modalOpen('Title', '<p>Content</p>');

// Programmatically close
modalClose();

Features

  • ✅ ESC-Key schließt Modal
  • ✅ Backdrop-Click schließt Modal
  • ✅ Focus-Trap für Accessibility
  • ✅ Responsive Design (Mobile-friendly)
  • ✅ Smooth Animationen
  • ✅ Body Scroll-Lock
  • ✅ ARIA-Labels für Screen Reader

API Reference

// modalOpen(title, content)
modalOpen('Dialog Title', '<p>HTML content here</p>');

// modalClose()
modalClose();

// isModalActive() - Check if modal is open
if (isModalActive()) {
    console.log('Modal is open');
}
